# StudyWithCyrene

昔涟陪着你学习的 DSH 插件。它在学习时段里随机截取当前屏幕，先用本地规则 + Windows OCR 判断，模糊时才让 DeepSeek 看一眼图；连续两分钟没有学习证据，就用一块盖住所有显示器的全屏提醒把你叫回来。总结、提问、每 13 分钟的鼓励，都尽量用昔涟的语气。

## 功能

- 「开始学习 / 停止学习」：开始的时候只填一个领域（比如「深度学习」），关键词由插件自己准备。
- 随机 0–120 秒截图：只截前台窗口所在的那块屏幕，压到 1280px，判完即删。
- 本地优先：进程名、窗口标题、Windows 自带 OCR、领域关键词；不调模型、不花 token。
- 混合视觉：只有规则和 OCR 都判不出来时，才把一张图发给当前视觉模型，限频 1 次/2 分钟。
- 全屏提醒：连续 120 秒没有学习证据就弹全屏窗口，按钮「我回来了 / 休息一下 / 不想学啦」；检测到重新学习会自动关。
- 桌面悬浮球：开始学习时在屏幕右下角出现，点击展开面板；DSH 最小化也还在，可以随时看计时或点「休息一下」。
- 总结：点「总结」总结从开始或上次总结到现在的这一段；点「结束学习」补最终总结和整场报告（时长、分布、中断、重点）。
- 提问：点「提问」或结束学习时，根据这段学习历程出 3–5 道由浅入深的自测题，答案折叠。
- 鼓励：连续学习满 13 分钟弹一个不挡操作的角落提示；26、39 分钟再来；中断或休息后重新计时。
- 统计：今天 / 本周 / 本月总学习时长、本周和本月的平均每天学习时长、0–23 点分布、中断次数。
- 设置：截图区间、视觉开关、悬浮球开关、提示音。
- 夸夸门槛：在你第一次完整坚持到 13 分钟之前，总结和统计不主动夸你，只做客观回顾；第一次夸夸亮起来后才会出现。

## 安装

1. 确认插件目录在 DSH 工作区：`plugins/dsh-study-with-cyrene`。
2. 在 DSH 的插件管理里安装本地 bundle，或者在 profile 的插件管理器中用 `link:` 指向这个目录。
3. 启用 `dsh-study-with-cyrene`，刷新 DSH Web 页面；右侧栏会出现「StudyWithCyrene」页签。

如果你是从 GitHub 克隆的：

```bash
git clone <仓库地址>
```

然后在 DSH 插件管理里用 `link:<克隆下来的目录>` 安装，或把目录放进 profile 的 `node_modules` 后启用。

## 使用

打开右侧栏「StudyWithCyrene」→ 输入领域 → 开始学习。学习期间 DSH 可以最小化，但不要完全退出；完全退出后监督停止。开始后屏幕右下角会出现一个悬浮球，点它展开面板；面板里的「收起」会缩回球，DSH 最小化不影响它。

全屏提醒里的三个按钮：

- **我回来了**：关掉提醒，重新给 2 分钟宽限。
- **休息一下**：先不关提醒，按钮会变成「继续学习」，让你在提醒里歇一会儿；准备好了再点「继续学习」回来。
- **不想学啦**：关掉提醒，给 10 分钟宽限；这段时间里不再弹提醒。

长按 `Esc` 3 秒可以强制关掉提醒（仍然会给 2 分钟宽限）。

## 隐私与成本

- 截图只写到系统临时目录，判完立即删除；OCR 在本地完成。
- 只有开启视觉、且画面模糊时，才把一张 **压缩后** 的截图发给当前模型；视觉图片会进入 DSH 的附件库（内容寻址，插件没有删除 API）。不想留图片就把「视觉」关掉，本地 OCR 仍然工作。
- 总结 / 提问按需调用模型；13 分钟鼓励是预写静态句，0 token。
- 纯本地模式 0 token；混合模式在每天 4 小时、30–120 次视觉抽查的情况下，大约 ¥1.5–6/月（DeepSeek Flash 空闲价，高峰翻倍）。实际以你的账单为准。
- 学习记录和关键词缓存在 `~/.dsh/study-with-cyrene/state.json`；删掉它等于清空统计和缓存。

## 已知边界

- 插件只能看见电脑屏幕：玩手机、看纸质书、发呆是盲区；看纸质书或暂时不想学时可以按「不想学啦」拿 10 分钟宽限。
- 管理员权限运行的应用、独占全屏游戏可能盖不住全屏提醒。
- Windows OCR 需要系统有对应语言包；没有时自动退回标题 / 关键词判断。
- 视觉只在当前模型支持图片输入时启用；切到纯文本模型会自动关视觉。
- 统计按会话开始日期归档；跨午夜的长会话会归到开始那天，属于近似值。

## 开发

- Host：`lib/index.js`（Cordis 插件，Node ESM）。
- Client：`lib/client.js`（`window.__ModuleLoader__.load` 浏览器 bundle，无构建步骤）。
- PowerShell：`scripts/foreground.ps1`（前台轮询）、`capture.ps1`（截图 + OCR）、`popup.ps1`（全屏提醒）、`float.ps1`（桌面悬浮球）、`toast.ps1`（角落鼓励）。
- 安装后可以用 `GET /study-with-cyrene/api/health` 做冒烟检查（请求头 `X-Study-With-Cyrene: 1`）。
